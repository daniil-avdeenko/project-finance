💰 Финансы проектов
Веб-приложение для учёта доходов и расходов по проектам с аналитикой и управлением сотрудниками.

Возможности:
- Управление проектами, сотрудниками, категориями и транзакциями
- Расчёт прибыли и рентабельности в реальном времени
- Интерактивный график рентабельности за 6 месяцев
- Фильтрация транзакций по дате и типу, пагинация
- Экспорт данных в CSV (UTF-8 с BOM)
- Ролевая модель: администратор и пользователь

Стек технологий:
- Python 3, Flask, SQLAlchemy, Flask-Login, WTForms
- SQLite
- Bootstrap 5, Chart.js, Font Awesome

Установка и запуск:

1. Клонируйте репозиторий:
   git clone <url>
   cd WebProject

2. Создайте и активируйте виртуальное окружение:
   python -m venv venv
   source venv/bin/activate      # Linux/Mac
   venv\Scripts\activate         # Windows

3. Установите зависимости:
   pip install -r requirements.txt

4. Примените миграции:
   flask db upgrade

5. Заполните тестовыми данными:
   python seed.py

6. Запустите приложение:
   python run.py

После запуска приложение доступно по адресу http://127.0.0.1:5000

Пользователи (после выполнения seed.py):
- Администратор: admin / admin
- Пользователь: user / user
Администратор имеет полный доступ: управление проектами, сотрудниками, категориями, 
а также редактирование и удаление любых транзакций.
Пользователь может просматривать все данные, создавать транзакции и экспортировать отчёты, 
но не может редактировать или удалять существующие записи.


Структура проекта:
app/
├── models.py          # Модели БД
├── forms.py           # WTForms
├── helpers.py         # Вспомогательные функции
├── routes/            # CRUD для всех сущностей
├── templates/         # HTML-шаблоны
└── static/            # CSS и др.
run.py                 # Точка входа
seed.py                # Наполнение тестовыми данными

Ключевые функции:
- Дашборд – статистика за выбранный месяц или весь период.
- График – рентабельность проектов за последние 6 месяцев с выбором проектов.
- Экспорт – CSV для проектов, сотрудников и транзакций (UTF-8 с BOM).

Примечания:
- Все формы защищены CSRF.
- Маршруты защищены декораторами @login_required и @admin_required.
- Поле «Сумма» в транзакциях принимает числа с пробелами и запятыми (автоочистка).
- При удалении категории проверяется наличие связанных транзакций.
